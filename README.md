# 나의 과제

팀(Claude)들이 내 준 오늘의 과제를 한곳에서 보고, 풀이·답을 기록하는 설치형 웹앱(PWA)이에요.

- 주소: https://kimgimky-prog.github.io/my-tasks/
- 기록은 폰 안(localStorage `my-tasks.v1`)에만 저장돼요. 서버가 없어요.
- 팀과 주고받는 내용은 비공개 '우편함' 저장소를 써요. 열쇠(토큰)는 폰에만 저장되고 이 저장소에는 들어가지 않아요.
- 자정까지 답이 없는 과제는 '미완료'로 기록되고 우편함을 통해 팀에 알려져요.
- 카톡 메시지를 '공유' → '나의 과제'로 보내거나, 복사해서 붙여넣어도 과제가 들어가요.

## 파일

| 파일 | 하는 일 |
|---|---|
| index.html | 화면의 뼈대 |
| style.css | 색·글꼴·배치 |
| mailbox.js | 우편함(GitHub)과 주고받기 |
| app.js | 화면 동작, 저장, 미완료 처리, 붙여넣기 |
| sw.js | 인터넷 없이도 열리게 파일 보관 (고친 뒤 VERSION 올리기) |
| manifest.webmanifest | 폰 설치 정보, 카톡 공유 받기 |
